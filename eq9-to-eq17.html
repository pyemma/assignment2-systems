What the matrix in Equation 9 actually is

For a single row, Pj = exp(Sj) / Σk exp(Sk). Differentiating one probability with respect to one score gives

∂Pj / ∂Sk = Pj (δjk − Pk)

Read across a fixed j and down the keys k, and that is one row of diag(P) − PP⊤. The diagonal holds the “own numerator” term Pj(1 − Pj). Every off-diagonal holds the “shared normalizer” term −Pj Pk.

The same multiply, drawn so the shared scalar shows up

Look at row 0 only. Every entry in that row already contains the factor P0 = 0.20. Pull it out, and the three-term dot product becomes one subtraction.

Write the dot product once, for a general key

Row j of the Jacobian, column k, is Pj (δjk − Pk). Dot it with dP:

dSj = Σk Pj (δjk − Pk) dPk

Pj does not depend on k, so it leaves the sum. The Kronecker delta keeps a single term:

dSj = Pj · dPj − Pj · Σk Pk dPk

The sum is a scalar. Name it.

D = Σk Pk dPk
dSj = Pj (dPj − D)

Put the query index back on, and this is Equation 17. The matrix diag(Pi) − Pi Pi⊤ was real; it just never has to be stored. Its action on dPi is an elementwise multiply by Pi after subtracting one number from every entry of dPi.

Two pieces, two jobs. Subtracting Di removes the part of dP that is only a shared baseline, which softmax cannot see, because adding a constant to every score in the row does not change P. Multiplying by Pij is the local scale from the derivative Pj(1 − Pj) and from the coupling −Pj Pk, both of which carry a factor Pj.

Why this form can be recomputed

Equation 9, written as a matrix, asks you to hold P from the forward pass and then build an N×N Jacobian. Equation 17 asks for two thinner things: the probabilities themselves, and one scalar Di per query.

The scalar, without the length-N row

Di = Σj Pij dPij still looks like it needs the full probability row. Substitute the two definitions that produced those vectors. dPij is the dot of dOi with value row j, and Oi is Pi mixed with V:

Σj Pij dPij = Σd Oid dOid

The sum over keys and the sum over the head dimension are the same contraction. On this example, O = (0.50, 0.80) and dO = (0.40, −0.20), and

0.50·0.40 + 0.80·(−0.20) = 0.20 − 0.16 = 0.04

which is the D already computed from P · dP. So D is rowsum(O ∘ dO), available from the forward output and the output gradient before any key tile is revisited.

The probabilities, rebuilt per tile

The forward pass saved the log-sum-exp Li = log Σj exp(Sij) instead of P. A tile of scores is S = QK⊤ / √d again, and

Pij = exp(Sij − Li)

is Equation 14. Together with dP = dO V⊤ from Equation 16, every ingredient of Equation 17 is either recomputed for the current query tile and key tile, or already sitting in the length-Nq vector D.

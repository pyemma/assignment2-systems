How a Triton tile load builds pointers and a mask

The two lines below turn a program id into a 2D tile of addresses, then mark which of those addresses actually sit inside the tensor.

ptrs = x_ptr + rows[:, None] * x_stride_row + cols[None, :] * x_stride_dim
mask = (rows[:, None] < NUM_ROWS) & (cols[None, :] < D)

1. The indexes are still 1D

The program id chooses where the tile starts. tl.arange fills in the offsets inside the tile. With ROWS_TILE_SIZE = 2, D_TILE_SIZE = 4, and row_tile_idx = 1:

rows = [2, 3]          # shape (2,)
cols = [0, 1, 2, 3]    # shape (4,)

rows are the row coordinates of this tile. cols are the column coordinates. Nothing is two-dimensional yet.

2. Broadcasting builds the grid

rows[:, None] has shape (2, 1). cols[None, :] has shape (1, 4). Adding or comparing them broadcasts to shape (2, 4), one entry per element of the tile.

rows[:, None]                cols[None, :]
[[2],                        [[0, 1, 2, 3]]
 [3]]

broadcast row index          broadcast col index
[[2, 2, 2, 2],               [[0, 1, 2, 3],
 [3, 3, 3, 3]]                [0, 1, 2, 3]]

Position (i, j) in that grid is the logical coordinate (rows[i], cols[j]).

3. Strides turn coordinates into addresses

For a contiguous row-major matrix, x_stride_row = D and x_stride_dim = 1. With D = 6:

offset(i, j) = rows[i] * 6 + cols[j] * 1

so the pointer grid is x_ptr plus:

[[12, 13, 14, 15],
 [18, 19, 20, 21]]

Row-major offsets of m n o p are 12–15. Offsets of s t u v are 18–21. tl.load(ptrs) reads that whole tile at once.

The address formula is the same one a block pointer uses internally:

address(i, j) = base + i * strides[0] + j * strides[1]

4. The mask is the same grid, compared with the boundary

mask = (rows[:, None] < NUM_ROWS) & (cols[None, :] < D)

Same broadcast, but the result is booleans. With NUM_ROWS = 5 and D = 6, every entry of the tile above is inside the tensor, so the mask is all true.

The last row tile is where the mask matters. If row_tile_idx = 2, then rows = [4, 5] while NUM_ROWS = 5:

TrueTrueTrueTrue FalseFalseFalseFalse

rows[:, None] < 5 for rows 4 and 5. Columns 0–3 are all inside D = 6, so only the row check fails.

tl.load(ptrs, mask=mask, other=0.0) still receives a (2, 4) tile of pointers. It only dereferences the True lanes. The False lanes become 0.0 and are not read.

The matrix still ends at row 4 (y z A B C D). The tile wants a second row that is not in the allocation. The value returned by tl.load is still shape (2, 4):

yzAB 0000

Row 4 is loaded. The missing row is filled with other=0.0 and is not read from memory.

5. The same check with a block pointer

The program id still picks the tile. tl.make_block_ptr stores the boundary instead of building the mask tensor yourself:

make_block_ptr does not apply the mask. tl.load(..., boundary_check=(0, 1), padding_option="zero") does. boundary_check=(0,) checks rows only, (1,) checks columns only, and (0, 1) is the full 2D mask.
